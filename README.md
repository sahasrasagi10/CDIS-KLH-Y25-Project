# Cloud-Based Weather Data Collection and Forecast Dashboard

## Project Description

The **Cloud-Based Weather Data Collection and Forecast Dashboard** is a web-based application designed to collect, store, monitor and analyse weather information through a centralized cloud platform.

The system collects simulated or publicly available weather data, including temperature, humidity and rainfall. It provides a user-friendly dashboard to display weather information through graphical visualizations and helps users analyse historical weather trends.

The application also supports date-based filtering, historical data analysis and forecast display. AWS cloud services are used for application hosting, data storage, monitoring, networking and access management.

## Key Features

- Weather data collection
- Cloud-based data storage
- Interactive weather dashboard
- Graphical representation of weather parameters
- Historical weather analysis
- Date-based data filtering
- Weather forecast display
- Application monitoring

## AWS Services

- **Amazon EC2** – Application hosting
- **Amazon S3** – Weather dataset and backup storage
- **Amazon RDS** – Structured weather data storage
- **Amazon CloudWatch** – Application monitoring
- **Amazon VPC** – Network configuration
- **AWS IAM** – Access and permission management
